# Security Policy

## Supported Versions

| Version | Supported          |
|---------|-------------------|
| 1.0.x   | ✅ Current         |
| 0.8.x   | ✅ Supported       |
| < 0.8   | ❌ Not supported   |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public issue
2. Email: [Open a private security advisory](https://github.com/ABCrimson/use-resize-observer/security/advisories/new)

We will acknowledge receipt within 48 hours and provide a timeline for a fix.
